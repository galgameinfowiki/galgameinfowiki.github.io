这个圈子的缩写和日语借词特别多，但它们大多只是在描述「故事怎么组织」「画面怎么构成」「版本怎么发行」。这里把 47 个高频词按五组整理，每条一句话讲清，不堆黑话。

基础概念

Galgame / ギャルゲーgal game
中文圈对「美少女游戏」的俗称，源自日语「ギャルゲーム」。最初泛指以女性角色为主要卖点的电脑游戏，1990 年代中期后逐渐与「恋爱冒险 / 恋爱模拟」画上等号。
美少女游戏bishōjo game
日语「美少女ゲーム」的直译，与 Galgame 在多数语境下可互换，日语语境里更正式一些。
视觉小说Visual Novel / VN
以文字叙事为主体、配合立绘、背景、音乐与配音的互动小说形态。1996 年 Leaf 社在《雫》上首次使用这一叫法，用来强调「文字铺满画面、像在屏幕上读小说」的表现方式。
AVG / ADVAdventure Game
冒险游戏的缩写。日式语境里的「文字 AVG」通常指通过阅读文本、做出选择推进剧情的作品，与视觉小说高度重叠，但更强调「选项与分支」这一玩法层。
音效小说Sound Novel
Chunsoft 在《弟切草》等作品中使用的叫法，强调音效与氛围对文字叙事的烘托，是视觉小说概念的重要前身。
乙女游戏Otome Game
面向女性玩家、以男性角色为攻略对象的恋爱冒险游戏。玩法框架与 Galgame 相似，区别主要在目标受众与视角。
全年龄向all ages
不含限制级内容、面向一般玩家发行的版本。同一部作品可能同时存在原版与全年龄版，购买时请以商店分级标注为准。
泣きゲー / 催泪游戏nakigē
以细腻的情感铺垫与命运转折让玩家落泪的子类型，1998 年《ONE ～光辉的季节～》与 1999 年《Kanon》确立其范式，Key 社是代表厂商。
萌系 / 日常向moe
以角色魅力与轻松日常为主要卖点的作品取向，与「剧情向」相对，二者并没有高下之分。

玩法与结构

路线 / 线route
围绕某位角色展开的分支剧情。多数作品由一条共通线分岔出若干角色线，各线共同拼出完整世界观。
共通线common route
所有角色尚未分岔前的公共剧情，负责介绍人物、铺设定与埋伏笔。
个人线character route
进入特定角色之后的专属剧情，通常也是该角色情感线与结局的落点。
选项choice
玩家在关键节点做出的选择，是推动分支、改变好感度或触发结局的主要交互方式。
Flag / 剧情标志flag
游戏内部记录「某条件是否已达成」的标记。玩家口中的「立 Flag」也常指某段台词预示了后续剧情走向。
好感度affection value
隐藏或可见的数值系统，用来判断玩家与目标角色的关系进度，常见于养成类作品。
多结局multiple endings
同一部作品存在若干结局，由选项、好感度与路线进度共同决定。
True End / 真结局TE
揭示核心伏笔与世界观、通常被视为「完整答案」的结局，往往需要通关其他路线后才会解锁。
Bad End / 坏结局BE
因错误选择或未满足条件而导向的负面结局，有时也承担补充信息的作用。
Normal End / 普通结局NE
介于 Bad End 与 Good End 之间、可收束但不圆满的结局。
Good End / Happy EndGE / HE
该角色线相对圆满的收束，未必解释全部伏笔。
周目playthrough
从头到尾完成一遍游戏。多周目指读档或重开以体验其他路线、解锁隐藏内容。
存档 / 读档save / load
在关键选项前存档，是体验多分支最常用也最省时的做法；Quick Save / Quick Load 是快捷键版本。
Skip / 跳过已读skip
快进已读过的文本，多周目时用来快速回到分歧点；未读文本通常不会被跳过。
Backlog / 对话记录backlog
回看已读文本的功能，也常用于回听语音。
Auto / 自动播放auto mode
按设定节奏自动推进对话，适合不想逐句点击、想专注阅读的玩家。

美术、声音与制作

立绘tachie
角色的半身或全身静态画像，叠在背景之上表现对话对象；表情与姿势的变化称为「差分」。
CG / 事件插画event CG
在关键剧情节点解锁的整幅插画，往往是一部作品美术资源的重点，也是玩家收集欲的来源。
背景background art
场景美术，配合立绘构成画面。近年作品常加入镜头移动、粒子与光效等「演出」。
原画genga
负责角色设计与插画绘制的职位或稿件，一部作品的画风通常由原画师决定。
脚本 / 剧本scenario
承担剧情撰写与结构设计的工作，长篇作品常由多位剧本家分线负责。
声优 / CVvoice actor
为角色配音的演员。部分作品主角不配音，以便玩家代入。
BGMbackground music
背景音乐。这个类型的音乐与剧情情绪绑定极深，许多主题曲至今仍被单独传唱。
OP / EDopening / ending
片头曲与片尾曲，通常伴随动画影像，是作品印象的重要组成部分。
演出direction
文字出现节奏、画面切换、音效与音乐配合的综合调度，决定了「读起来是什么感觉」。

版本与发行

FD / Fan Discfan disc
本篇之后发行的扩充盘，常见内容是后日谈、番外短篇、追加路线或小游戏。
后日谈After Story
主线结局之后的延伸剧情，有时单独成篇，有时收录在 FD 中。
移植版port
从原平台移植到主机、掌机或移动端的版本，常追加新要素或调整分级。
全年龄版all-ages edition
删去限制级内容、面向一般渠道发行的版本；部分作品会同时补全剧情与新增 CG 作为补偿。
汉化 / 本地化localization
把日文文本翻译为中文的工作。官方中文版（如 Steam 中文）在翻译一致性与兼容性上通常更稳妥。
初回限定版limited edition
首批生产、附带原声集或设定集等特典的版本，二手市场价格常因此波动。
Steam 版Steam release
面向国际数字发行平台的版本，常支持多语言、价格更低，也是近年中文读者最主要的正版渠道。

社区用语

推 / 推完play through
「推一部作品」即完整游玩；「推完某条线」指读完该角色路线。
剧透spoiler
提前得知关键伏笔或结局。这个类型极依赖叙事反转，社区普遍有较严格的防剧透习惯。
傲娇tsundere
外表强硬、内心温柔的角色类型，源自日语「ツンデレ」。
青梅竹马 / 幼驯染osananajimi
与主角自幼相识的角色设定，是校园题材里最常见的关系之一。
萌moe
对角色或作品产生的喜爱与情感投射，中文语境里也常作形容词使用。
评分站 / 批评空间review database
玩家用来记录通关、打分与写短评的数据库型站点，是查口碑时常用的第三方参考。
